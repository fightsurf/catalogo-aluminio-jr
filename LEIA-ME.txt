PATCH DE CORREÇÃO VISUAL — STATUS ZAP / AGENDAMENTOS
Base: projeto Render de 24/10/2026 + patch do agendador já aplicado.

OBJETIVO
- Ajustar o modal de Agendamentos de Publicações ao estilo do sistema,
  com controles alinhados e apresentação responsiva no computador e celular.
- Adicionar na tela principal um mostrador com estado do agendamento,
  próxima categoria, contagem regressiva e horário da próxima execução.
- Corrigir o desalinhamento da busca de cliente cadastrado na primeira linha.

COMO INSTALAR
1. Extraia o ZIP.
2. Envie os arquivos para o GitHub, preservando exatamente as pastas.
3. Substitua os arquivos existentes:
   - views/whatsapp/status-whatsapp.html
   - public/js/status-agendamentos.js
4. Adicione o arquivo novo:
   - public/css/status-agendamentos.css
5. Aguarde o deploy do Render e recarregue a tela /whatsapp/status.

IMPORTANTE
- Este patch é incremental: requer que o agendador entregue anteriormente
  já esteja instalado, conforme informado pelo usuário.
- Não substitui servidor, rotas, serviço de agendamento ou API local.
- Não requer SQL, instalador Python ou variáveis novas.
- O contador atualiza a cada segundo; os dados do servidor são atualizados
  periodicamente, sem depender do modal estar aberto.
- O horário é apresentado no fuso America/Sao_Paulo (horário de Brasília).
- O próximo agendamento pode ser recalculado pelo servidor após o fim de
  uma publicação, conforme a lógica original do agendador.

VALIDAÇÃO
- Código JavaScript validado por node --check.
- Layout testado com navegador Chromium em telas de desktop e celular,
  utilizando respostas simuladas da API, sem publicar conteúdos reais.
- A execução em produção e os canais externos não foram testados.
