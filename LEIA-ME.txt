PATCH - PUBLICAÇÃO DE FOTOS NO STATUS DO WHATSAPP
Projeto-base analisado: render(54).zip

O QUE FOI CRIADO
- Página para selecionar várias fotos do computador.
- Ordenação das fotos antes do envio.
- Legenda geral ou legenda individual.
- Publicação sequencial com um único clique.
- Intervalo configurável entre as fotos.
- Verificação da conexão da Z-API.
- Progresso, identificação de falhas e reenvio somente das falhas.
- Proteção contra clique/requisição duplicada enquanto o servidor estiver ativo.
- Recebimento de uma foto por vez em memória, sem Cloudflare, sem banco e sem gravação em disco.
- Limite de 12 MB por imagem. Formatos: JPG, PNG e WEBP.

COMO APLICAR
1. Envie os arquivos do ZIP para o projeto do Render no GitHub, mantendo exatamente as pastas.
2. Substitua os arquivos existentes quando solicitado.
3. Faça o deploy.
4. Acesse: https://catalogo-aluminio-jr.onrender.com/whatsapp/status

VARIÁVEIS DE AMBIENTE
O módulo reutiliza as mesmas variáveis que o envio de mensagens atual já utiliza:
- ZAPI_URL
- ZAPI_TOKEN

Não é necessário criar variável nova se o envio atual pelo WhatsApp já funciona.
ZAPI_URL deve terminar em /instances/ID_DA_INSTANCIA/token/TOKEN_DA_INSTANCIA.
ZAPI_TOKEN corresponde ao Client-Token enviado no cabeçalho.

BANCO DE DADOS E PROJETO LOCAL
- Nenhum SQL precisa ser executado.
- O banco de dados não foi alterado.
- O projeto local(52) não precisa ser alterado.

OBSERVAÇÃO
A página precisa permanecer aberta durante o envio porque as imagens não são armazenadas no servidor.
