CORRECAO REVISADA DO CLOUDFLARE R2 - PROJETO render(56)

A analise confirmou que o patch anterior nao estava aplicado no projeto atual.

Substitua no projeto do Render:

1. src/services/cloudflare/cloudflareR2.service.js
2. .env.example
3. render.yaml

O que foi corrigido:
- remove espacos e aspas acidentais das variaveis de ambiente;
- aceita CLOUDFLARE_R2_ENDPOINT opcional;
- impede URL no campo CLOUDFLARE_R2_BUCKET;
- remove o nome do produto dos metadados assinados;
- mantem apenas metadados ASCII simples;
- inclui ContentLength no PutObject;
- melhora o log e a mensagem dos erros do R2;
- recria o cliente se a chave secreta for alterada.

DEPOIS DE SUBIR AO GITHUB

1. Faca novo deploy no Render.
2. Teste o upload sem alterar as variaveis atuais.
3. Se ainda aparecer SignatureDoesNotMatch, revise no Render:

CLOUDFLARE_R2_ACCOUNT_ID
CLOUDFLARE_R2_ACCESS_KEY_ID
CLOUDFLARE_R2_SECRET_ACCESS_KEY
CLOUDFLARE_R2_BUCKET
CLOUDFLARE_R2_PUBLIC_URL

CLOUDFLARE_R2_ENDPOINT pode ficar vazio para bucket comum.

ACCESS_KEY_ID e SECRET_ACCESS_KEY precisam pertencer ao mesmo token R2.
Nao coloque aspas. O bucket deve conter somente o nome, nao uma URL.
